# Security policy

## Report a vulnerability privately

Please do not report security problems in public issues, discussions or comments.

Use GitHub's private reporting: open the [Security tab](https://github.com/tensorsofthewall/playnice-windows/security) of this repository and choose **Report a vulnerability**, or go directly to <https://github.com/tensorsofthewall/playnice-windows/security/advisories/new>. Only the maintainer can see a private report.

Please include:

- The PlayNice version (**About PlayNice**) and your Windows version.
- What you found and why it matters.
- Steps to reproduce it, if you can.

Do not include passwords, personal data or anything you are not allowed to share.

## What to expect

This is a small project run by one maintainer. There is no guaranteed response time. Reports are read and answered as soon as the maintainer is able to.

## Supported versions

Only the latest PlayNice release is supported. PlayNice is in early testing, and fixes are published as new releases.

## Not security reports

Audio problems, crashes that do not involve a security impact, and feature requests belong in [issues](https://github.com/tensorsofthewall/playnice-windows/issues/new/choose).

## Downloads

Download PlayNice only from this repository's [Releases page](https://github.com/tensorsofthewall/playnice-windows/releases). Each release lists a SHA-256 checksum, which tells you the file was not damaged or changed after it was published; it does not by itself show that a file is safe. If Windows or your security software reports a problem with a PlayNice download, do not turn off protection to run it: [report it](https://github.com/tensorsofthewall/playnice-windows/issues/new/choose) or use private reporting if you think it is serious.
